\section{First}

This points to the 2nd cont. figure: \ref{fig:firstA}

This program shows a problem with the combination of the 
{\bf hyperref} and the {\bf caption} packages when used with 
{\em pdflatex}.  The problem is that the internal PDF identifier
({\tt$\backslash$@currentHref}) needs to be unique and is not for
continued figures.

The current state-of-things generates OK document text, but 
the PDF document is not correctly linked.
